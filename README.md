### Framework de Automação de Testes

- Estruturação da automação utilizando Page Object Model (POM), Fixtures e Hooks, priorizando reutilização, organização

testes ao processo de integração contínua.
- Aplicação de práticas de organização e manutenção de código voltadas à escalabilidade da suíte de automação.
